# Security Policy

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security bugs by emailing **muigastephen14@gmail.com**. Include:

- A description of the vulnerability
- Steps to reproduce or proof-of-concept
- The potential impact
- Any suggested mitigations

You will receive a response within 72 hours. We will work with you to understand and address the issue, and will credit you in the release notes unless you prefer to remain anonymous.

## Scope

This policy covers the Beacon frontend application at `https://github.com/ORIGIN-HQ/UNDP-frontend`. The backend API is maintained separately — please report backend vulnerabilities to the same email.

## Out of scope

- Vulnerabilities in third-party dependencies (report upstream)
- Issues that require physical access to the device
- Social engineering attacks
